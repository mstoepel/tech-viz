Isolation levels are a list of lies you agree to be told

Two transactions run at once against one table. Interleave their statements by hand. At each isolation level the database is allowed to show you something slightly untrue, in exchange for speed — and each level forbids exactly one more kind of untruth than the last.

Engine notes. Same shell as the other sandboxes. The engine is a toy MVCC: a committed table with per-row versions, per-transaction private writes, row locks for write/write conflicts, and a read rule per isolation level. Repeatable read here follows the SQL standard (rows you've read stay stable; new rows can appear). Postgres and MySQL implement it as snapshot isolation, which is stricter and stops phantoms too. Serializable is snapshot plus first-committer-wins.
