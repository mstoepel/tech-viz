Sandbox 02 · Git internals

A branch is just a pointer

Not a folder, not a copy, not a timeline. A branch is a 41-byte file holding one commit id, and HEAD is a file holding a branch name. Merge and rebase look complicated until you watch which files they write.

Commit graph · older ← → newer
HEAD reachable commit unreachable (no ref points here) ◎ merge commit
.git/ — the files behind the graph
Every command on this page does nothing but append commit objects and rewrite these files.

Engine notes. Same shell as The Three Trees: immutable state, pure reducers, a parser, a D3 renderer that diffs state against the DOM, and a LESSON array. Here the state is a commit DAG plus a map of ref files; there are no file contents and therefore no merge conflicts. Conflicts are about content; this page is about shape.
