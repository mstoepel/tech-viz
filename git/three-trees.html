Engine notes. Everything below the fold is four separable parts: an immutable state, a registry of pure (state, args) → {state, out} reducers, a parser, and a D3 renderer that only ever diffs state against the DOM. A lesson is data, not code — see LESSON. Swap the reducers and the renderer and the same shell teaches transaction isolation or LSM compaction.
