Destroy the data on a schedule. Learn to undo one step

A diffusion model has two halves. The forward half is a fixed recipe that adds noise until nothing is left — no learning, no choices. The only thing that is learned is a single function: given a noisy point and how noisy it is, which way is the data? Run that function backwards fifty times and you have a generator.

Engine notes. Same shell as the other sandboxes, with clickable controls issuing the same commands. The forward process is the real closed form with a cosine schedule over 50 steps. The "model" is the exact Bayes-optimal denoiser for the training set — a kernel average of the training points weighted by how likely each is to have produced the noisy input — which is what a perfectly trained network would converge to. smooth widens that kernel to imitate a smaller model that can't memorise. Sampling is DDIM (deterministic). Guidance is classifier-free: the conditional denoiser only sees one class's points, and the strength interpolates or extrapolates between it and the unconditional one.
