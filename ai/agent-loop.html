Sandbox 01 · AI systems

An agent is a while loop around a function that forgets everything

The model has no memory, no hands, and no idea a loop exists. Each call it is handed the entire conversation so far and returns either an answer or a request to run a tool. Everything that makes it feel like an agent — tools running, results coming back, stopping, remembering — is plumbing on the outside. Type to it, then step the loop.

Engine notes. Same shell as the other sandboxes. The "model" is a deterministic policy over the context — it decides by regex what a real model decides by weights — so that the loop is the thing under the microscope, not the model's judgement. Token counts are characters ÷ 4. Everything else is exactly how a real runtime is wired: the model gets the whole context every call, tools are functions the runtime chooses to run on the model's request, and memory is a tool like any other.
